# 4.2.2 Attribute and Value Errors

## Test Cases for Attribute Validation

[REQ] Invalid status value

Audit logging system must record all administrative actions.

```yaml
attrs:
  id: REQ-AUDIT-001
  func: F_AUDIT_001
  parent: AUDIT-STK-001
  derive: 'no'
  safety: 'no'
  alloc: Audit Module
  status: InProgress
```

[REQ] Invalid derive value

Backup system must support incremental and full backups.

```yaml
attrs:
  id: REQ-BACKUP-001
  func: F_BACKUP_001
  parent: BACKUP-STK-001
  derive: 'maybe_partial'
  safety: 'no'
  alloc: Backup Module
  status: Active
```

[REQ] Invalid safety attribute value

Data compression system must reduce storage requirements by 40-60%.

```yaml
attrs:

  func: F_COMPRESS_001
  parent: COMPRESS-STK-001
  derive: 'no'
  safety: 'maybe'
  alloc: Compression Module
  status: Active
```

[REQ] Function ID with invalid format

Caching system must use LRU eviction policy.


Load balancing system must distribute requests evenly.
