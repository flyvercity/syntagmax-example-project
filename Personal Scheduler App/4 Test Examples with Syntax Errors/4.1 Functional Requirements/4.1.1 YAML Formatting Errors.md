# 4.1.1 YAML Formatting Errors

## Test Cases for YAML Attribute Block Validation

[REQ] Missing colon in YAML key

Calendar system must support multiple timezone configurations.

```yaml
attrs
  id: REQ-YAML-001
  func: F_CAL_001
  parent: CAL-STK-001
  derive: 'no'
  safety: 'no'
  alloc: Calendar Module
  status: Active
```

   derive: 'no'
