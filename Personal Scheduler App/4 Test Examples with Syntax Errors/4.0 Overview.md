# Chapter 4: Test Examples with Syntax Errors

## Overview

This chapter provides comprehensive test examples designed to validate parser robustness and error handling. Each requirement contains intentional syntax errors to test the system's ability to detect, report, and gracefully handle malformed content.

## Error Categories

The test examples are organized by error type:

1. **YAML Formatting Errors** — Invalid YAML syntax in attribute blocks
2. **Markdown Structure Errors** — Malformed markdown tables and lists
3. **Formula/Code Errors** — Invalid LaTeX and code block formatting
4. **ID and Reference Errors** — Invalid requirement IDs and parent references
5. **Attribute Errors** — Missing, duplicate, or invalid attribute values
6. **Encoding and Special Character Errors** — UTF-8 and special character issues

## Test Objective

These examples validate:
- Parser error detection and reporting
- Graceful degradation when encountering malformed input
- Clear error messaging for debugging
- Recovery mechanisms for partial failures
